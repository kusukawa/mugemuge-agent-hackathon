# クラウドの費用の見積もり

作成: 2026-10-06（M3 完了時点の構成）。対象: プロジェクト `mugemuge-agent`、リージョン `asia-northeast1`（東京、Tier 1）。

> 単価は作成時点で把握していたものを使った**目安**。実際の額は1〜2日後に Cloud Billing のレポートで確かめ、ずれていればこのファイルを直す。

## 今の構成

| サービス | 設定 | 課金のされ方 |
|---|---|---|
| Gateway（`mugemuge-gateway`） | CPU 1、メモリ 512MiB、`--min-instances=1`、`--max-instances=1` | **デバイスの WebSocket がつながっている間は「処理中」の扱い**で、CPU・メモリが常に使用中の単価で課金される |
| Web/API（`mugemuge-web`） | 最小0台 | 使ったときだけ |
| Agent（`mugemuge-agent`） | 最小0台、CPU を常時割り当てない | 使ったときだけ（承認の再開はイベント駆動なので常駐不要） |
| Gemini（Vertex AI、`gemini-3.8-flash`） | — | トークン量に応じて |

## 月の見積もり

| 項目 | 月の目安 | 計算 |
|---|---|---|
| **Gateway（Pi が24時間接続）** | **約60ドル（約9,000円）** | CPU: 1 vCPU × 259.2万秒 − 無料枠18万 vCPU秒 ≒ 241万 × 0.000024ドル ≒ 58ドル。メモリ: 0.5GiB × 259.2万秒 − 無料枠36万 GiB秒 ≒ 94万 × 0.0000025ドル ≒ 2ドル |
| Gateway（Pi が未接続の時間） | その時間ぶんは約1/10 | 最低1台（`--min-instances=1`）は待機中の安い単価 |
| Web/API・Agent | 0〜数ドル | リクエストのある間だけ |
| Gemini 3.8 Flash | 1会話あたり1〜数円程度 | 「同定して10秒測る」で LLM 呼び出し約6回 |
| Artifact Registry | 0.5〜1ドル | ADK 入りのイメージがデプロイごとに溜まる |
| Firestore・Secret Manager・Cloud Trace・Logging | ほぼ0 | 無料枠内の見込み |

**合計: Pi を常時接続したままなら月に約62〜65ドル（約9,500円）。12/1 まで（約56日）で約115ドル（約1.7万円）。**

費用のほとんどは、Gateway の WebSocket が24時間つながっていることによる。

## 下げ方

| 方法 | 効果 | 代償 |
|---|---|---|
| 使わないときは Pi のデーモンを止める | 止めている時間は約1/10 | — |
| Gateway を `--min-instances=0` にする | デバイス未接続ならほぼ0円 | 接続時の起動が数秒遅れる（デーモンは張り直すので動作に問題なし） |
| Artifact Registry に古いイメージの自動削除を設定する | 保管料を抑える | — |
| 予算アラート（例: 月30ドル） | 超えそうになったらメール | — |

## M4（仮想デバイス）の費用（2026-10-06 に方針を決定）

人の判断で「使う人ごとにその場で作る」方式にした（常時1台の共有はしない）。

| 項目 | 目安 | 理由 |
|---|---|---|
| 仮想デバイスのサービス（`mugemuge-virtual`） | 使っている間だけ、1時間あたり約0.09ドル（CPU 1・512MiB、インスタンス課金） | 外向きの WebSocket を保つため CPU を常時割り当てる。最小0台なので、誰も使っていなければ0円 |
| Gateway | 仮想デバイスがつながっている間は「処理中」 | Pi が常時つながっているなら追加の費用はほぼない（同じインスタンスが処理する） |
| Gemini | 1会話あたり1〜数円 | 審査員の操作量しだい |

- 寿命（既定60分）と同時台数（既定10台）で上限をかけている。10台が60分ずっと動いても、インスタンスは1つなので約0.1ドル
- Cloud Run はリクエストのない状態が15分ほど続くとインスタンスを止める。止まれば課金も止まる（画面を閉じたまま放置しても費用は増えない）

## 長期の記録と写真（2026-10-06 に追加）

| 項目 | 目安 | 理由 |
|---|---|---|
| Firestore（記録のバッチ） | 1秒ごと×7日で約0.1ドル | バッチは30秒か120行ごとに1ドキュメント（7日で約2万件の書き込み） |
| Firestore（記録ページを見る） | 7日分を「全部」で開くと約0.01ドル | バッチを全部読んで間引く（約2万件の読み取り） |
| Cloud Storage（写真） | 5分ごと×7日（約2,000枚・約300MB）で月に1円未満 | 東京の Standard。90日で自動的に消える |
| Gateway | 追加なし | 記録の送信は同じ WebSocket |

- Pi 側の spool は既定で 50MB まで（超えたら写真を撮らない）
- 写真のバケットは公開しない。画面には Web/API が、見る権限を確かめてから中継する
